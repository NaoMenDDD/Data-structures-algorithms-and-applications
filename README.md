> 一套从 0 到 1、可直接执行的中文自学资料：以 Sartaj Sahni《数据结构、算法与应用（C++ 版）》为知识骨架，把每个数据结构与算法都落到**现代机器学习 / 深度学习 / 世界模型**的真实场景上。
>
> 写给：**非计算机专业、C++ 与数学基础扎实、即将进组做世界模型（world models）研究**的同学。

## 0. 这套资料想解决什么问题

大多数数据结构教材有两个问题：

1. **只讲"是什么"，不告诉你"为什么"和"在哪儿用"** —— 学完 AVL 旋转、KMP 失配函数，却不知道这些东西在真实系统里出现在哪一层。
2. **与今天的 AI 完全脱节** —— 你明明要做的是世界模型，教材却在用"学生成绩管理系统"举例。这让人怀疑"学这个到底有没有用"。

本资料的目标是消除这两个断层。每一章都包含固定的一节：**「与 AI / 世界模型的连接」**，明确回答：

> 这个数据结构 / 算法，在我未来要做的研究里，**具体出现在哪个环节**？

例如：

| 你在教材里学的 | 它在世界模型研究里的真实落点 |
|---|---|
| 数组与矩阵的行/列主序、stride | PyTorch 张量的 `view` / `transpose` / `contiguous`，`NCHW` vs `NHWC` 对卷积性能的影响 |
| 矩阵乘法与循环次序 | GEMM、cuBLAS、FlashAttention 的分块思想 |
| 优先级队列与堆 | Top-k 采样、beam search、A\* 搜索、Dijkstra 规划、优先经验回放 |
| 图与拓扑排序 | 计算图（DAG）、反向传播的求导顺序、GNN 消息传递、场景图 |
| 动态规划 | Viterbi 解码、CTC、编辑距离、Bellman 方程（强化学习与最短路同构） |
| 哈希与散列 | 词表、KV cache、embedding 检索、LSH/MinHash 去重、Bloom filter |
| NP 难与近似 | 世界模型中的规划为何需要采样/学习式搜索，神经组合优化 |

**一句话**：本资料不把数据结构当"考试科目"，而把它当**你未来研究系统的底层零件目录**。

## 1. 适合谁 / 不适合谁

**适合你，如果**：

- 你是非计算机专业本科生（或研究生），C++ 会写但不系统；
- 数学基础扎实（会微积分、线性代数、概率论，看得懂 $\sum$、$\log$、极限）；
- 你要（或即将）进入 ML / DL / 世界模型 / 具身智能方向，需要补齐工程与算法基础；
- 你希望**看得懂框架源码、写得出高效算子、理解训练与推理系统的性能瓶颈**。

**不太适合，如果**：

- 你完全没有编程基础（请先补 C++ 语法再回来）；
- 你只想应付考试、不打算写代码（本资料每章都有可编译的完整实现，跳过代码等于白学）。

## 3. 怎么用这套资料

**核心原则：不要"读"，要"跑"。** 每一章的完整实现都能直接编译运行，请务必亲手跑一遍、改一遍、测一遍。

推荐的三步法：

1. **先看结构，再看细节**：打开一章，先读「本章目标」和「本章小结」，建立骨架；再回头逐节精读。
2. **手敲代码，不要复制粘贴**：`code/` 里的程序是**答案**，不是练习。请先自己写，写不出来再看；跑通后尝试改坏它（改边界、改扩容策略），观察行为变化。
3. **做完练习再看答案**：练习按「基础 / 进阶 / 挑战」分层，答案收在 `<details>` 折叠块里。挑战题不会做是正常的，先记录，二刷再攻。

### 编译与运行示例

```bash
cd "MyGit/Data structures-algorithms-and-applications"
g++ -std=c++17 -O2 -Wall -Wextra code/02_array_list.cpp -o /tmp/ds02 && /tmp/ds02
```

建议额外打开消毒器（能抓出越界、悬垂指针、未定义行为——数据结构代码的头号杀手）：

```bash
g++ -std=c++17 -O1 -g -fsanitize=address,undefined code/03_chain.cpp -o /tmp/ds03 && /tmp/ds03
```

## 8. 常见问题（FAQ）

**Q：我是非科班，C++ 只学过语法，能看懂吗？**
A：能。第 00 章专门为这个设计，把后面所有章节会用到的 C++ 特性（模板、RAII、迭代器、移动语义）一次性补齐。

**Q：数学基础要多好？**
A：会 $\sum$ 符号、对数、指数的基本运算，理解极限即可。第 01 章的递推式求解会用到一点高中数列知识，Master 定理直接给结论并配例子，不要求会证明。

**Q：学完真的能"掌握这门课"吗？**
A：如果你把每章的代码亲手写一遍、练习做完，能。但"掌握"的标志不是"看过"，而是：**给你一个具体问题，你能判断该用什么结构、复杂度多少、边界在哪、怎么在 C++ 里高效实现**。第 16 章的自测清单就是用来检验这一点的。

**Q：为什么反复强调"和 AI 连接"？我不会为了面试背八股。**
A：因为你的目标是研究，不是考试。不理解"堆为什么出现在 beam search 里"，你会在读论文代码时一脸茫然；理解了，你会发现自己能**主动把算法工具箱用到研究问题**上——这才是这套资料真正的价值。
